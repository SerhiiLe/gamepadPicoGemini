# Прошивка и настройка GP2040-CE

Хорошая и универсальная штука. Но своеобразная и не очевидная.

[https://gp2040-ce.info/](https://gp2040-ce.info/)

## Прошивка

Прошивается как обычно, зажал boot нажал и отпустил reset появился диск, скопировал готовую прошивку.

Но дальше возникает вопрос - что делать? Например у меня "распиновка" как на картинке с сайта не заработала. Она там для примера, а не как руководство к действию. Для этого надо попасть на web. А что-бы попасть туда нужно станцевать такой шаманский танец:

- Скачайте официальный файл: 👉 [force_webconfig.uf2](https://github.com/OpenStickCommunity/GP2040-CE/releases/download/v0.7.12/force_webconfig.uf2) (v0.7.12, выбрать нужную версию)
- Зажмите микрокнопку BOOT на самой плате Waveshare RP2040-Zero и вставьте USB-кабель в ПК.
- В системе появится диск RPI-RP2.
Скопируйте файл force_webconfig.uf2 на этот диск.
Плата перезагрузится и принудительно (без нажатия каких-либо клавиш) запустит веб-конфигуратор!
- Это разовая акция, по этому сразу надо идти по адресу [http://192.168.7.1](http://192.168.7.1/) и настроить клавиши, сохранить.
- После этого включение режима будет нажатием кнопки "menu" при включении, или нажатии кнопки reset на контроллере.

Если вдруг RNDIS не сработал и USB-Ethernet не появился, то надо самостоятельно загрузить модуль
```bash
sudo modprobe rndis_host
```

## Настройка

### Настройка кнопок

Надо указать такую привязку:
- B1 (A / Cross) → GP8
- B2 (B / Circle) → GP7
- B3 (X / Square) → GP9
- B4 (Y / Triangle) → GP6
- L1 (LB) → GP2
- R1 (RB) → GP3
- L2 (LT) → GP0
- R2 (RT) → GP1
- S1 (Select / Back) → GP15
- S2 (Start) → GP5
- L3 → GP19
- R3 → GP4
- A1 (Home / Central) → GP10
- Up → GP14, Down → GP12, Left → GP13, Right → GP11

Дать название профилю и сохранить.

### Настройка стиков

Аналоговые стики добавлены в GP2040-CE просто как второстепенный плагин (вкладка Add-Ons -> Analog).

- Далее надо указать пины для стиков, указать оси для левого и правого стиков.
- Указать инвертирование осей (X)
- Указать мертвую зону
- Указать сглаживание (80)
- Указать скругление квадрата

Сохранить.

### Дополнительно

Там море параметров, но полезность их под вопросом. Часть вообще непонятно как работает. Есть возможность делать макросы и свои функции, но это требует отдельной выделенной клавиши Fn, которую надо физически припаять.

Светодиод настраивать бесполезно, он несёт декоративную функцию.

Всякие vibro и прочие предметы роскоши тоже мимо. Только управление.

Настройки можно сохранять себе на диск в файл, а при необходимости восстанавливать настройки из файла. Это удобно. Можно заготовить несколько профилей и быстро их менять.
