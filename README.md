# Проект для выяснения как работает стандарто HID для gamepad.

Проект рабочий, представляет из себя четыре варианта gamepad, так как единого стандарта HID не существует.

- Совместимый с Linux/Steam (зажатие X при старте, цвет Циан)
- Совместимый с Android (зажатие A при старте, цвет Оранжевый)
- Совместимый с Nintendo Switch (зажатие B при старте, цвет Красный)
- Совместимый с протоколом Sony DualShock 4 (зажатие Y при старте, цвет Белый / Lightbar)

## Реализованные варианты

Так-же реализована утилита на Python которая может проверить индикацию и вибрацию.
`sudo tools/gamepad_tester.py --gui`

или просто в консоли.

### Linux/Steam

Основная проблема этого варианта, как и следующего, это количество кнопок и осей. Кроме обычных сейчас A B X Y ещё должны быть C Z. Они занимают виксированное место в порядке клавиш и если делать, как я в начале, без пропусков на эти клавиши, то порядок ломается, а часть кнопок просто не работает.

Порядок осей тоже имеет значение: X Y - левый стик, rX rY - правый стик. Отдельным блоком определяются курки-тригеры - Z - левый, rZ - правый.

Обратная связь в виде управления светодиодом или вибрации не поддерживается.

Активация этого режима - при включении надо зажать кнопку X, светодиод будет гореть тусклым сине-зелёным цианом.

### Android

Такие-же пропуски на клавиши C Z, как у версии под Linux/Steam, но с другим назначением осей. Эти клавиши C и Z оставлены для совместимости с gamepad от Sega. В современных играх они не используются и игнорируются, в репортах они всего 0, то есть не нажаты. Но в некоторых программах для проверки gamepad видят эти кнопки и ожидают нажатия для проверки.

Порядок осей: X Y - левый стик, Z rZ - правый стик. Отдельным блоком определяются курки-тригеры - rX - левый, rY - правый.

Несмотря на такое малое отличие раскладки становятся полностью не совместимыми и не пригодными.

Обратная связь в виде управления светодиодом или вибрации так-же, как и для Linux/Steam не поддерживается.

Активация происходит нажатием A при включении. Светодиод будет гореть тусклым оранжевым.

### Sony DualShock 4

Тут нет пропусков, работает вибрация и управляется светодиод. Но работает только с Linux/Steam. С консолями не работает, так как нужен оригинальные сертификат и серийный номер оригинального gamepad. По Android теоритически должне работать начиная с Android 12, но по факту на Android 14 он не видится.

Расположение осей как у версии под Android.

В этой прошивке установлены заглушки под беспроводное соединение, заряд аккумулятора, гироскоп и тачпад с кнопкой тачпада. Они обязаны быть, но их нет в этом маленьком проекте. Sony сильно нагрузили свои gamepad по сравнению с примитивными от Xbox. Но цены одинаковые из-за сертификатов, которые обязаны покупать произодители железок. Без этого они не будут работать с приставками, только с компьютером.

Включается этот режим нажатие кнопки Y при включении. Светодиод будет гореть тусклым белым, пока цвет не измениться командами со стороны компьютера. Он полноцветный и может иметь любой цвет, но по умолчанию он синий.

### Nintendo Switch

Официальные контроллеры Nintendo Switch Pro требуют сложного криптографического обмена, но начиная с версии прошивки 3.0.0 в консоли Nintendo Switch есть нативная поддержка стандартных проводных USB HID контроллеров (протокол **HORI Pokkén Tournament Pro Pad**, VID `0x0F0D`, PID `0x0092`).

Этот режим работает «из коробки» как с самой консолью Nintendo Switch (в док-станции или через USB-C OTG), так и со Steam (который автоматически распознаёт раскладку Nintendo A/B/X/Y) и Linux/PC.

Раскладка кнопок физически ориентирована под стандарт контроллеров Nintendo:
- Правая кнопка -> A (подтверждение)
- Нижняя кнопка -> B (отмена / назад)
- Верхняя кнопка -> X
- Левая кнопка -> Y
- Курки и бамперы: L, R, ZL, ZR
- Системные клавиши: Minus (-), Plus (+), L3, R3, HOME.

Активация режима — при включении зажать кнопку B. Светодиод загорится фирменным **красным цветом** Nintendo.

## Варианты за пределами этого проекта

## Универсальное решение GE2040-CE

Есть готовая прошивка, которую даже компилировать не надо. [https://gp2040-ce.info/](https://gp2040-ce.info/) Клавиши и стики настраиваются через web, который поднимается через RNDIS драйвер (ethernet over usb). И там тоже есть выбор какой протокол имитировать нажимая клавиши при старте. Но там нет такого управления светодиодом :) Вместо этого там надо поставить отдельные 4 светодиода и OLED экранчик. Получается круче, но требует более сложной схемы и сборки. Или просто не пользоваться этими дополнительным возможностями. Так-же из интересного - можно подключать дополнительные платы ADC что позволяет сделать полный набор осей с полным разрешением. И гироскоп. Есть возможность загружать реальные сертификаты, если их найти на форумах.

## Проект Xbox

Проект на голом Pico SDK работает как надо. Работает всё, определяется Android. Воспринимается всеми играми без ремапа от Steam. Но не работает с приставками.
